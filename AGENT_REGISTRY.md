## REGISTERED AGENTS

### SEKANI
**Role:** Chief Intelligence and Coordination Agent
**Status:** Active
**Responsibilities:**
- Orchestrate all AI interactions in the RALD Ecosystem
- Route requests to appropriate agents based on BBC intent
- Enforce BBC compliance for all AI requests
- Manage the Model Router (OpenRouter)
- Coordinate the Event Bus
- Maintain awareness of all agent states

**Permissions:**
- Read/write to all agent memory (via WIZMAC)
- Route requests to any agent
- Invoke any model via Model Router
- Access full knowledge graph

**Memory Scope:** Full ecosystem

---

### WIZMAC
**Role:** Knowledge Graph and Institutional Memory
**Status:** Active
**Responsibilities:**
- Store ALL permanent memories for the RALD Ecosystem
- Maintain origin records (never deleted)
- Maintain decision registry
- Maintain event log
- Maintain language and voice knowledge
- Serve as institutional memory for the next century
- Be the ONLY system allowed to permanently remember things

**Permissions:**
- Permanent write to all WIZMAC tables
- Read access to all ecosystem data
- Authority to mark records as permanent
- Authority to version and supersede decisions

**Memory Scope:** Permanent, all scopes, all time

## DATABASE TABLES

All agent data is stored in WIZMAC:

- `agent_registry` — Agent definitions, roles, permissions
- `agent_tasks` — Tasks assigned to agents
- `agent_events` — Events emitted by agents
- `agent_memory` — Agent memory (routed through WIZMAC)
- `agent_reports` — Reports generated by agents
- `agent_relationships` — Agent-to-agent relationships
