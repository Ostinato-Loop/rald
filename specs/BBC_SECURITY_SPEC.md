## 1. MANDATE

Every request in the RALD Ecosystem MUST pass through BBC before model execution.

BBC is not optional. BBC is not a filter. BBC is the gate.

---

## 2. BBC PIPELINE (WITH SECURITY STAGES)

```
INPUT (Voice / Text / API)
  │
  ▼
[1] Input Sanitization
  │  Strip injection patterns
  │  Enforce size limits
  │  Validate encoding
  │
  ▼
[2] Language Detection
  │  Detect language, dialect, accent
  │  Reject invalid/unrecognized input
  │
  ▼
[3] Intent Detection
  │  Classify: query / request / command / statement
  │  Flag: abuse / harassment / threat / policy violation
  │
  ▼
[4] Risk Assessment
  │  Compute trust score (0.0–1.0)
  │  Factor: IP reputation, actor history, content patterns
  │  HIGH RISK → block and log security event
  │
  ▼
[5] Policy Validation
  │  Check against active BBC policies
  │  Enforce: content policy, rate limits, agent permissions
  │  POLICY VIOLATION → reject, audit log, security event
  │
  ▼
[6] Model Routing (only if all stages pass)
  │  Route to appropriate model via OpenRouter
  │
  ▼
[7] WIZMAC Audit
     All interactions logged permanently
```

## 3. SECURITY POLICIES

### Rate Limiting
- Anonymous: 60 requests / minute
- Authenticated: 300 requests / minute  
- Agent-to-Agent: 1000 requests / minute
- Voice pipeline: 30 recordings / minute per user

### Input Limits
- Text: 50,000 characters max
- Voice: 10MB audio max, 5 minutes max
- API payload: 5MB max

### Risk Scoring
- 0.0–0.4: Pass
- 0.5–0.7: Pass with audit flag
- 0.8–0.9: Require additional verification
- 0.9–1.0: Block, generate security event

### Blocked Patterns
- SQL injection attempts
- Prompt injection attempts
- PII in public fields
- Credential patterns in text
- Shell command injection

## 4. AUDIT TRAIL

Every request generates an audit record:

```typescript
{
  requestId: uuid,
  actor: string,
  agentRole: string,
  action: string,
  resource: string,
  result: "success" | "failure" | "blocked",
  duration: ms,
  ipAddress: string,
  riskScore: float,
  occurredAt: timestamp,
}
```

Audit records are permanent. Audit records cannot be deleted.

---

## 5. SECURITY EVENTS

Generated by Agent 4 (FOUR):

- `auth.failure` — Authentication failure
- `rate.limit.exceeded` — Rate limit violation
- `policy.violation` — BBC policy violation
- `injection.attempt` — Injection pattern detected
- `anomaly.detected` — Unusual traffic pattern
- `credential.exposure` — Credential pattern in input
- `agent.misuse` — Agent permission violation

All security events are stored in WIZMAC permanently.
